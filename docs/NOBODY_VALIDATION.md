## 局部差异不能忽略

- hybrid 对 V8：全关节差 P95 为 **0.201°**，最大为 **22.918°**，位于零基帧 57、**1.14 s、右膝**。
- frax 对 V8：全关节差 P95 为 **0.583°**，最大为 **48.964°**，位于零基帧 741、**14.82 s、左肩 yaw**。
- 这些是不同优化方法/分支之间的差值，不是相对人体真值的误差。足部合格和全片 P95 小，均不能证明局部姿态等价；躯干最大误差也明显高于 V8。
- 已检查预览的首、中、末帧及上述局部窗口附近画面，机器人完整可见、同步时间一致。未把截图检查写成人工逐帧动作验收。
