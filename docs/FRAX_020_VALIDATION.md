# Dex-Frax 0.2.0 第一轮改良 — 2026-11-05

默认入口现在是 `--mode frax`。本轮改动仅在 Dex-Frax，未改变同级正式
Dex-SuperMimic V8、机器人模型、物理关节限位或逐轴速度额定值。

## 改动与原因

1. **膝分支偏好**：在 frax 目标中增加单边软残差，偏好至少 1° 屈曲，权重 3。
   原模型允许的小幅膝过伸仍然允许；这是重定向偏好，不是新增机械限位。
   它避免本样例在接近伸直时卡在 -5° 分支，但不能保证所有输入都没有负角度。
2. **接触朝向过渡**：第 413 帧的最大膝加速度与脚尖到平脚的目标朝向突变重合。
   对相邻、无腾空间隔的接触片段，在朝向跳变超过 3° 时用最多 0.1 s 的
   五次过渡连接。保留接触权重和锚点，按原凸包重新计算落地高度。nobody 共处理
   11 个过渡、每个 5 帧。没有对最终关节角做平滑滤波。
3. **困难窗口联合拟合**：躯干朝向误差超过 1° 或上半身加速度超过 400 rad/s²
   时，合并并向两侧扩展 0.4 s。只在这些窗口做稀疏姿态/限速 SQP，加入二阶差分；
   根部、腿部、窗口两端各 2 帧固定。nobody 只处理 `[712,770)` 共 58 帧，约 0.6 s。
   400 rad/s² 是选窗启发值，不是硬件限值。超过 4 s 的窗口、活动上肢支撑或失败
   求解保留原轨迹并报告原因，最终审核不跳过。
4. **局部手臂避碰**：快速版现在也调用已修复的 V8 联合手臂选择。只处理碰撞窗口，
   不默认执行完整 V8 支撑及全片手臂分支规划。

主要代码：`src/dex_frax/ik.py`、`contact_transition.py`、`local_refine.py`，
入口衔接在 `v8/convert.py` 和 `cli.py`。`hybrid` 保留原始 frax 初始解及完整 V8
后处理；`v8` 保留正式 V8 对照。`--mode frax --legacy-frax` 重现旧快速版消融。

`training.npz`，不表示已完成策略跟踪或可直接在真机执行。

这是原帧和插值采样检查，不是连续碰撞证明或所有机器人几何对的证明。
